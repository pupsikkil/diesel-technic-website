# Дизель Техник - Корпоративный сайт логистической компании

Современный корпоративный сайт для международной логистической компании "Дизель Техник", основанной 14 декабря 2011 года.

## 🚀 Технологии

- **React 18+** с TypeScript
- **Vite** как сборщик
- **Tailwind CSS** для стилизации
- **shadcn/ui** компоненты
- **Framer Motion** для анимаций
- **React Hook Form** для форм
- **Lucide React** для иконок

## 📦 Установка и запуск

1. **Установите зависимости:**
```bash
npm install
```

2. **Запустите проект в режиме разработки:**
```bash
npm run dev
```

3. **Соберите проект для продакшена:**
```bash
npm run build
```

4. **Предварительный просмотр продакшен сборки:**
```bash
npm run preview
```
